== Implementation resources

=== SHACL shapes

The `SHACL` directory contains one SHACL shapes graph per AIM module (for example `agriCrop-SHACL.ttl`), generated by `generateSHACL.sh`. The shapes can be used to validate instance data against AIM. They are informative in this version; a future version may add a normative SHACL validation requirements class for AIM data.

=== JSON-LD contexts

The `jsonld` directory contains one JSON-LD context per module and the combined `demeterAgriProfile-context.jsonld`. The contexts allow JSON documents, including GeoJSON and OGC API responses, to be interpreted as AIM RDF data. See <<rc_jsonld-context>>.

=== OGC Building Blocks

The repository is configured as an OGC Building Blocks register (`bblocks-config.yaml`, `_sources`). The building blocks package AIM concepts (for example farm and plot) with JSON schemas, JSON-LD contexts, SHACL rules and validated examples, for use with OGC APIs. See <<OGC-BB>>.
