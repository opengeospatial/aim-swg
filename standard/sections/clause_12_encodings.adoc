== Encodings

=== General

The canonical representation of AIM version 3.0 is the set of Turtle files in the `v3.0` directory. This clause specifies requirements for that encoding and for the derived RDF/XML and JSON-LD context encodings published by the AIM SWG in the `rdf` and `jsonld` directories.
