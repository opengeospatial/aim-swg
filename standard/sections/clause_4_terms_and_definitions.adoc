== Terms and definitions

=== ontology module

self-contained OWL ontology, identified by an ontology IRI and a version IRI, that defines or reuses a coherent set of classes and properties for one part of AIM

=== ontology profile

ontology that defines no terms of its own and aggregates other ontology modules by importing them

=== canonical representation

representation of an AIM ontology module that is authoritative for the module's content

NOTE: For AIM version 3.0 the canonical representation is the Turtle files in the `v3.0` directory of the AIM SWG repository.

=== implementation specification

specification, schema or software artefact that represents some or all of the AIM ontology modules for the purpose of data exchange
