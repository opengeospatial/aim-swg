[[annex_examples]]
== Examples

=== Overview

The `examples` directory of the AIM SWG repository contains instance data that uses AIM version 3.0, in Turtle and JSON-LD. <<table_examples>> lists them.

[[table_examples]]
.AIM version 3.0 examples
[cols="3,5",options="header"]
|===
|File |Content
|`simple-farm-instance-AIM_v3.{ttl,jsonld}` |A farm with two plots, crops and crop types.
|`complex-farm-instance-AIM_v3.{ttl,jsonld}` |A farm with parcels, crops, interventions and observations.
|`example-timeseries-healthPrediction-final_v3.{ttl,jsonld}` |Animal health predictions as a time series (RDF Data Cube).
|`example-timeseries-milkQualityPrediction-final_v3.{ttl,jsonld}` |Milk quality predictions as a time series (RDF Data Cube).
|`instance-bad-AIM_v3.jsonld`, `instance-bad2-AIM_v3.jsonld` |Invalid instances, for testing SHACL validation.
|===
