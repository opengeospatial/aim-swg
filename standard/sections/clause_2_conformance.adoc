== Conformance

This Standard defines requirements for representations of the AIM ontology modules and for encodings of those modules.

Requirements for the following standardization targets are considered:

* *Ontology module representation*: a representation of one or more AIM ontology modules, such as an OWL ontology, an implementation specification or a schema derived from AIM;
* *Ontology profile representation*: a representation of the AIM Agri Profile;
* *Encoded ontology document*: a document that encodes an AIM module in a particular RDF serialization; and
* *JSON-LD context document*: a JSON-LD context that maps JSON terms to AIM classes and properties.

Conformance with this Standard shall be checked using all the relevant tests specified in Annex A (normative) of this document. The framework, concepts and methodology for testing, and the criteria to be achieved to claim conformance, are specified in the OGC Compliance Testing Policies and Procedures and the OGC Compliance Testing web site.
