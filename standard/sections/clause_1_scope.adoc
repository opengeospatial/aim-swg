== Scope

This Standard specifies the Agriculture Information Model (AIM), version 3.0, as a modular set of OWL 2 ontologies for representing agricultural data and its context.

The Standard specifies:

* the identification, versioning and dependency structure of the AIM ontology modules;
* the classes and properties of the Cross-Domain, AgriCommon and agricultural domain modules (AgriFeature, AgriCrop, AgriIntervention, AgriAlert, AgriProduct, AgriProperty, AgriSystem, AgriPest and FarmAnimal);
* the AIM Agri Profile, which aggregates the domain modules; and
* requirements for Turtle, RDF/XML and JSON-LD context encodings of the modules.

Alignments to other models (e.g. NGSI-LD), extension modules, SHACL shapes, JSON schemas and OGC Building Blocks are described informatively and are not normative in this version.

This Standard does not specify any API, service interface or storage mechanism.
