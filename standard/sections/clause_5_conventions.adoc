== Conventions

=== Identifiers

The normative provisions in this Standard are denoted by the URI

`http://www.opengis.net/spec/aim/1.0`

All requirements and conformance tests that appear in this document are denoted by partial URIs which are relative to this base.

=== Term dictionaries

The term dictionaries in Clauses 8 to 11 are generated from the canonical Turtle files by `scripts/ontology_tables.py`. Each dictionary lists every class or property declared in the module with its `rdfs:label`, its definition (`skos:definition`, or `rdfs:comment` where no definition is given) and its superclasses or domain and range. Where a dictionary and the canonical Turtle file differ, the Turtle file takes precedence.
