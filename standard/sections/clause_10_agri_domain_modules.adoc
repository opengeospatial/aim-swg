== Agricultural domain modules

=== General

This clause specifies the Tier 3 modules of AIM. Each module imports the AgriCommon module (<<rc_agri-common>>) and can be adopted independently of the other domain modules.

=== AgriFeature module

==== Overview

The AgriFeature module describes the physical and administrative features of agriculture: farms, holdings, sites, parcels, plots, management zones, greenhouses and farm buildings.
