== Abstract

The Agriculture Information Model (AIM) is a multi-tier, modular domain model for agriculture. It aligns, profiles and extends well-known agriculture-related and generic ontologies, including ontologies published by OGC and W3C (SOSA/SSN, GeoSPARQL, OWL-Time), ETSI (SAREF, SAREF4AGRI), INSPIRE, FOODIE and the FIWARE Smart Data Models.

AIM provides a common language for agriculture applications. It defines the concepts, properties and relationships relevant to agriculture, and their semantics, to harmonize and improve data and metadata exchange.

This Standard specifies AIM version 3.0 as a set of OWL ontology modules: a Cross-Domain module, an AgriCommon module, nine agricultural domain modules and an Agri Profile that aggregates them. The canonical representation is the Web Ontology Language (OWL 2) encoded in Turtle. The Standard also specifies requirements for derived encodings (RDF/XML and JSON-LD contexts). Informative annexes describe examples, alignments, extensions, SHACL shapes and OGC Building Blocks that support implementation.

In line with OGC policies and the FAIR principles, AIM resources are identified by persistent, resolvable URIs.
