[[req_agri-alert_properties]]
[requirement]
====
[%metadata]
identifier:: http://www.opengis.net/spec/aim/1.0/req/agri-alert/properties

[.component,class=part]
--
For each `owl:ObjectProperty` and `owl:DatatypeProperty` defined in the AgriAlert module, an implementation specification claiming conformance to this standard SHALL contain a construct representing the same property using the same identifier.
--

[.component,class=part]
--
The implementation specification SHALL preserve property characteristics defined in the ontology, including domain, range, inverse-property, and subproperty relationships, where those characteristics are provided.
--
====
