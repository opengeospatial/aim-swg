[[req_farm-animal_classes]]
[requirement]
====
[%metadata]
identifier:: http://www.opengis.net/spec/aim/1.0/req/farm-animal/classes

[.component,class=part]
--
For each `owl:Class` defined in the FarmAnimal module, an implementation specification claiming conformance to this standard SHALL contain a construct representing the same concept using the same identifier.
--

[.component,class=part]
--
The implementation specification SHALL preserve superclass relationships and class annotations defined for the FarmAnimal classes, where such relationships and annotations are provided in the ontology.
--
====
