[[ats_agri-property_properties]]
[abstract_test]
====
[%metadata]
identifier:: http://www.opengis.net/spec/aim/1.0/conf/agri-property/properties
target:: http://www.opengis.net/spec/aim/1.0/req/agri-property/properties
test-purpose:: Verify that every property defined in the AgriProperty module is represented with the same identifier and characteristics.

[.component,class=test method]
=====
[.component,class=step]
--
Retrieve the canonical AgriProperty ontology and the representation under test.
--

[.component,class=step]
--
For each `owl:ObjectProperty` and `owl:DatatypeProperty` declared in the canonical module, check that a construct with the same IRI exists in the representation under test.
--

[.component,class=step]
--
For each such property, check that `rdfs:domain`, `rdfs:range`, `owl:inverseOf` and `rdfs:subPropertyOf` statements of the canonical module are preserved.
--
=====
====
